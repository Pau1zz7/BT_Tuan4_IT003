Mô tả

So sánh thời gian thực thi 4 thuật toán sắp xếp:

\- QuickSort (pivot = phần tử giữa)

\- HeapSort (max-heap)

\- MergeSort (đệ quy)

\- std::sort (C++ STL - introsort)



Trên bộ dữ liệu gồm 10 dãy, mỗi dãy 1.000.000 số thực:
